# ピタッとタワー

左右に動くブロックをタップ（PCはスペースキー）で落として、ぴったり積み上げていくワンボタンゲーム。

- 正確に重ねるほど高得点。PERFECTを続けると倍率アップ（最大×2）
- 5連続PERFECTでFEVER、10段ごとにボーナス
- リザルト画面からシェア用のスクショを保存できます

## ファイル

- `index.html` … ゲーム本体（HTML / CSS / JavaScript を1ファイルに収録）
- `bgm.mp3` … BGM「デジタルレース」
